Learn From The Pages You Already Read

Fading Furigana is a browser extension plus learning app system for Japanese learners who want vocabulary practice to stay close to real reading.

1

Annotate Japanese Text

The extension scans webpage text locally and adds furigana to words it recognizes, while skipping forms, code blocks, and editable areas.

2

Save Useful Words

Click an annotated word to check its reading and meaning, then save it for review or mark it as known, forgotten, ignored, or pinned.

3

Review Locally

The Mac learning app keeps your library, daily review, activity, privacy choices, and storage health on the same device.

Local-First By Default

Annotation and Basic local learning do not require an account. Cross-device sync and cloud backup are not part of the Basic MVP.

  • ✓Webpage text is processed locally so the extension can add furigana.
  • ✓Saved vocabulary, review history, settings, and entitlement state are stored on your device.
  • ✓Page URL retention can be set to off, domain only, or full URL.
  • ✓Learning data is not sold and is not used for advertising.
