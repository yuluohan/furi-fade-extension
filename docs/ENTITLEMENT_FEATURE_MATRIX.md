## 注释与依据

- **¹ 订阅过期仍能本地保存新词**：Pro 是 Basic 之上的加购（订阅前必持有 Basic），因此 Pro 过期后回退到已持有的 Basic，本地学习闭环全保留，仅停同步/云端。见 `docs/MONETIZATION_TODO.md` 2026-06-15 决策块及第 277 行「不锁/不删本地数据」。
- **试用过期 vs 订阅过期的核心区别**：试用过期从未付费 → 新增保存被付费墙拦、注音降级有限预览；订阅过期是付费用户 → 本地一切照旧，只断云端能力。
- **永不锁本地数据**：任何状态下已存词库、历史、复习都可见可用，数据不删不藏。
